what is software testing?
-----
software testing is a part of a software development process 
software testing is an activity to detect and identify the defect in the software  
the object of testing is to release quality product to the customer or client


what is software quality??
-----
1. bug-free
2. delivered on time 
3. within budget
4. meets requirement or expectation 
5. maintainable 



project and product 
******
--- if software application is developed for specific customer based on the requirement then it is called project (no others)


--- if software application is developed for multiple customer based on market requirements then its called product

1. Quality of the product will be good (detailed document)
2. science Requirements change not allowed, the finding bugs will be less 
3. investments very less at initial

DIS

2. if there is defect in requirements that will be continued in later stage 
3. total investment is more, because time taking for rework on defect

* version vise software will be released 1,2,3,4, etc as cycle 
* its suitable for product based company (market based Requirements) iterate model 
* new model will be released for every cycle

1. spiral model is Iterative mode Version control model
2. SM overcome drawbacks of waterfall model 
3. we follow SM when ever there is a dependency on the previse model or software 
4. for every cycle new software will be released to customer  
5. so software released multiple version, so its called version control 



ADV VS DIS

ADV

1. Testing is done in every cycle, before its go to the next cycle
2. customer will get use the software for every model 
3. Requirements changes are allowed for every cycle, before going to the next cycle 

DIS 

1. Requirement changes are not allowed in b/w cycle 
2. every cycle of SM looks like Waterfall model 
3. There is no testing in requirements and design Phase

Verification and Validation 
--------------------------

Verification:- done or conduct before Software

* Focus on Documents

2. walkthrough
3. Inspection

Validation:- done or conduct After Software

* Validation takes place after verification are completed 
* Focus on Software
